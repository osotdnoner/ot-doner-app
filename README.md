# ОТ Донер — приложение администратора смены

Веб-приложение для администраторов «ОТ Донер»: отметка прихода на смену, приём смены по чек-листам, обходы, задачи и итоговый отчёт. Полное ТЗ и схемы — в документе «Приложение администратора «ОТ Донер»: ТЗ и архитектура».

## Что уже работает (этап 1, часть 1)

- Вход по номеру телефона и паролю.
- Кнопка **«Я пришёл на смену»**:
  - сервер проверяет, что администратор на территории своей точки (радиус настраивается);
  - время отметки берётся с сервера, поэтому перевод часов на телефоне не поможет;
  - обязательное селфи с живой камеры, загрузить фото из галереи нельзя;
  - опоздание считается автоматически, нужно указать причину, управляющему уходит сообщение в Telegram.
- Журнал всех попыток отметки, в том числе неудачных («вне территории», «слабый GPS»).
- Панель управления `/panel/`: точки, люди, смены с селфи и ссылкой на карту.
- Экран управляющего со сменами за сутки.

## Как устроен проект

```
config/          настройки и адреса страниц
accounts/        пользователи и роли (администратор, управляющий, собственник)
points/          точки: адрес, координаты, радиус, время смен
shifts/          смены и отметка «Я пришёл»
  services.py    правила: расстояние, какая сейчас смена, опоздание
  tests.py       автотесты
notifications/   отправка сообщений в Telegram
templates/       страницы
static/          стили, JavaScript (камера и геолокация), иконка
```

## Запуск на своём компьютере

Нужен Python 3.12 или новее: [python.org/downloads](https://www.python.org/downloads/). При установке на Windows поставьте галочку **Add Python to PATH**.

**1. Скачайте проект и установите библиотеки** (один раз):

Windows (PowerShell):
```
git clone https://github.com/ВАШ-АККАУНТ/ot-doner-app.git
cd ot-doner-app
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
python manage.py migrate
python manage.py createsuperuser
```

Mac / Linux:
```
git clone https://github.com/ВАШ-АККАУНТ/ot-doner-app.git
cd ot-doner-app
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python manage.py migrate
python manage.py createsuperuser
```

`createsuperuser` спросит логин: введите свой номер телефона (например `87011234567`) и придумайте пароль. Это ваш аккаунт для панели управления.

**2. Запустите сервер** (каждый раз, когда работаете):
```
python manage.py runserver
```

**3. Настройте данные** в панели: [http://127.0.0.1:8000/panel/](http://127.0.0.1:8000/panel/)
1. «Точки» → «Добавить»: название, координаты входа (в 2ГИС или Google Maps правый клик → скопировать координаты), радиус, время смен.
2. «Пользователи» → «Добавить»: телефон, имя, роль «Администратор смены», пароль. Затем откройте его и выберите точку в поле «Точки».
3. Себе в поле «Роль» поставьте «Управляющий» и тоже выберите точки, чтобы получать уведомления.

**4. Войдите как администратор:** [http://127.0.0.1:8000/](http://127.0.0.1:8000/)

## Проверка на телефоне

Браузер даёт доступ к камере и геолокации только по защищённому адресу (https). На компьютере это работает и так, а для телефона есть два пути:
- **Быстро, для пробы:** временный https-адрес через туннель, например [Cloudflare Tunnel](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/do-more-with-tunnels/trycloudflare/). Адрес туннеля нужно добавить в `.env`: в `ALLOWED_HOSTS` и в `CSRF_TRUSTED_ORIGINS`.
- **По-настоящему:** сервер VPS с доменом и сертификатом. Это следующий шаг проекта.

## Автотесты

```
python manage.py test
```
Тесты проверяют расчёт расстояния, выбор смены (включая ночную после полуночи), опоздание, отказ вне территории, слабый GPS, повторное нажатие и уведомление управляющему.

## Telegram

1. Создайте бота у [@BotFather](https://t.me/BotFather) и вставьте токен в `.env` → `TELEGRAM_BOT_TOKEN`.
2. Управляющий пишет боту любое сообщение, затем узнаёт свой chat ID (например, у бота @userinfobot) и вставляет его в своё поле «Telegram chat ID» в панели.

Пока токена нет, сообщения просто печатаются в окне, где запущен сервер.
